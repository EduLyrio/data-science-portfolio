# 01 · Tratamento de Valores Ausentes

Técnicas de limpeza e tratamento de valores ausentes em um conjunto de dados real.

**Destaques:**

- Identificação de valores ausentes padrão e não padrão (labels customizados via `na_values`)
- Análise do padrão de ausência antes de decidir a estratégia de tratamento
- Estratégias de imputação e remoção, com discussão dos trade-offs de cada abordagem

**Stack:** Python, Pandas, NumPy, Matplotlib

> Dados: fornecidos no curso da Data Science Academy (não incluídos no repositório).
