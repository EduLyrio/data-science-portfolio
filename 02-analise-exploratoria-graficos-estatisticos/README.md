# 02 · Análise Exploratória e Interpretação de Gráficos Estatísticos

EDA completa de um conjunto de dados, com comparação antes/depois da limpeza.

**Destaques:**

- Análise exploratória antes e depois do tratamento dos dados
- Tratamento de valores ausentes e outliers
- Análise univariada e interpretação de gráficos estatísticos (histogramas, boxplots, correlação)

**Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy

> Dados: fornecidos no curso da Data Science Academy (não incluídos no repositório).
