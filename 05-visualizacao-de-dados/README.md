# 05 · Técnicas de Visualização de Dados

Visualização de dados aplicada ao dataset de saúde processado no projeto 04 (Diabetes 130-US Hospitals após engenharia de atributos).

**Destaques:**

- Escolha do gráfico adequado para cada tipo de pergunta de negócio
- Visualizações de distribuição, comparação e relação entre variáveis clínicas
- Boas práticas de formatação e storytelling com dados

**Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn

> Dados: `dataset.csv` é a saída do [projeto 04](../04-engenharia-de-atributos-saude).
