# 📊 Portfólio de Análise de Dados com Python

Coleção de projetos práticos de análise de dados desenvolvidos em Python, cobrindo todo o ciclo de um projeto de dados: limpeza e tratamento, análise exploratória, engenharia de atributos, análise estatística e visualização.

## Projetos

| # | Projeto | Descrição | Principais técnicas |
|---|---------|-----------|---------------------|
| 01 | [Tratamento de Valores Ausentes](./01-tratamento-valores-ausentes) | Técnicas de limpeza e tratamento de valores ausentes em dados reais | Imputação, detecção de padrões de ausência, Pandas |
| 02 | [Análise Exploratória e Gráficos Estatísticos](./02-analise-exploratoria-graficos-estatisticos) | EDA completa com interpretação de gráficos estatísticos, tratamento de outliers | EDA, boxplots, histogramas, correlação |
| 03 | [Market Basket Analysis](./03-market-basket-analysis) | Regras de associação em dados de e-commerce de supermercado | Algoritmo Apriori, suporte/confiança/lift |
| 04 | [Engenharia de Atributos em Dados de Saúde](./04-engenharia-de-atributos-saude) | Feature engineering no dataset Diabetes 130-US Hospitals para estratificação de risco de readmissão | Recategorização, comorbidade, conhecimento de domínio |
| 05 | [Visualização de Dados](./05-visualizacao-de-dados) | Técnicas de visualização aplicadas aos dados de saúde processados no projeto 04 | Matplotlib, Seaborn, storytelling com dados |
| 06 | [Análise Estatística — Estudo Farmacológico](./06-analise-estatistica-farmacologia) | Análise de estudo pré-clínico de tratamentos contra tumores em camundongos | Sumário estatístico, EDA, SciPy |
| 07 | [EDA e Testes Estatísticos](./07-eda-testes-estatisticos) | Análise exploratória com testes estatísticos | NumPy, Pandas, SciPy |

## Tecnologias

Python · Pandas · NumPy · Matplotlib · Seaborn · SciPy · efficient-apriori · Jupyter Notebook

## Como executar

```bash
git clone https://github.com/EduLyrio/data-science-portfolio.git
cd data-science-portfolio
pip install -r requirements.txt
jupyter notebook
```

Cada projeto tem seu próprio README com detalhes sobre os dados e o passo a passo da análise.
